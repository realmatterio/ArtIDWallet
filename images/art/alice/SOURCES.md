# Artist Alice studio set

Ten original generative works made for this demo, so Artist Alice has a
collection of her own to register and sell. They are rendered by
`scripts/generate-alice-art.py` (fixed seeds, so the output is reproducible)
and carry no third-party rights.

| File | Title | Theme |
|---|---|---|
| `pearl-river-dusk.jpg` | Pearl River Dusk | Sunset over the delta, reflections on the water |
| `harbour-lights.jpg` | Harbour Lights | Night skyline mirrored in Victoria Harbour |
| `bauhaus-tram.jpg` | Bauhaus Tram | Geometric study in primary colours |
| `jade-current.jpg` | Jade Current | Flow field in jade greens |
| `lantern-grid.jpg` | Lantern Grid | Truchet tiling with festival lanterns |
| `lantau-mist.jpg` | Lantau Mist | Layered ridges in morning fog |
| `neon-kowloon.jpg` | Neon Kowloon | Neon signs and a synthwave horizon |
| `tidal-rings.jpg` | Tidal Rings | Moiré of two interfering ripples |
| `plum-blossom.jpg` | Plum Blossom | Ink branches with spring blossom |
| `signal-eight.jpg` | Signal No. 8 | A typhoon spiral and its warning signal |

The registry records point at these files on the repository's `main` branch;
the wallets show the bundled copy when the page is served from this folder
(see `artwork-drafts.js`).
